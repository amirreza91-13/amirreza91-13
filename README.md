## `01` — About Me

I'm a freelancer and software developer building practical skills through real projects, experimentation, and continuous learning.

My interests span software development, workflow automation, AI-assisted coding, local language models, and AI agents. I'm especially interested in connecting these technologies to solve useful problems rather than treating them as isolated tools.

* **Freelancing:** Working toward practical, useful digital solutions and software products.
* **Software Development:** Building applications, working with APIs, and exploring backend and web technologies.
* **Automation:** Creating and exploring workflows that reduce repetitive work and connect tools.
* **AI-Powered Development:** Using AI coding tools to support implementation, debugging, and project workflows.
* **AI Agents:** Exploring how models, tools, memory, and structured workflows can work together.
* **Long-Term Goal:** Progressing toward AI engineering and the development of reliable intelligent systems.

> I don't want to stop at using AI tools. I want to understand how to connect them, build with them, and turn them into useful systems.
