## `01` / ABOUT ME

Hi, I'm **Amirreza** — a developer on a journey toward **AI Engineering**, building my foundation through software development, practical experimentation, and continuous learning.

I'm interested in how software systems work, how different components communicate, and how artificial intelligence can become a useful part of real applications.

My approach is hands-on: write code, connect components, explore unfamiliar technologies, investigate problems, and improve what I build.

I don't see AI and software engineering as separate worlds. I see software engineering as the foundation for building more capable, useful, and reliable AI-powered systems.

**My direction:** stronger engineering fundamentals → intelligent applications → automation and AI agents → AI Engineering.

## `04` / HOW I THINK

```text
01  Learn the fundamentals.
02  Build something practical.
03  Understand how the system works.
04  Test assumptions and investigate failures.
05  Refine the implementation.
06  Turn experience into reusable knowledge.
```

* **Build to understand:** practical work is part of the learning process.
* **Think beyond the code:** understand components, interfaces, dependencies, and data flow.
* **Use AI thoughtfully:** leverage AI as a development tool while maintaining independent technical judgment.
* **Prefer evidence over assumptions:** distinguish what works in a test from what has merely been planned.
* **Improve continuously:** treat every implementation as an opportunity to learn and refine.
