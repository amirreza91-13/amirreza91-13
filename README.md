<h2 align="center">01 / THE MINDSET</h2>

I'm **Amirreza**, a developer building toward **AI Engineering through software development, experimentation, and continuous learning**.

I'm interested in the connection between software systems and artificial intelligence: how applications are structured, how APIs connect services, how language models can be integrated into useful tools, and how automation can turn repeated work into structured workflows.

My learning process is practical. I work with code, explore unfamiliar tools, investigate errors, and use projects to turn abstract concepts into working implementations.

I care about understanding the system behind the result—not just getting a result.

<p align="center">
  <strong>Understand the fundamentals. Build real things. Improve with evidence.</strong>
</p>

<h2 align="center">04 / ENGINEERING PRINCIPLES</h2>

* **Fundamentals before shortcuts** — understand the concepts behind the tools.
* **Working software over empty claims** — prioritize practical implementations.
* **Evidence over assumptions** — test behavior and investigate failures.
* **AI as a tool, not a substitute for thinking** — use assistance while developing independent judgment.
* **Systems over isolated snippets** — understand how components, APIs, and data fit together.
* **Continuous iteration** — learn, build, review, and improve.
